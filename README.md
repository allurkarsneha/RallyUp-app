# RallyUp

RallyUp is a sports social and booking mobile application built with Flutter. The app helps users connect with nearby players, join sports communities, manage bookings, and discover activities based on their interests. RallyUp combines social networking, sports discovery, and profile management into one streamlined experience focused on accessibility, usability, and modern mobile UI design.

---

## Features

### User Onboarding Flow
- Signup and login screens
- Name, phone number, and profile photo setup
- Sports preference selection

### Sports Discovery
- Browse sports categories
- Personalized sports preferences
- Interactive sports cards and filtering

### Profile and Account Management
- Profile settings
- Account verification and visibility controls
- Subscription management
- Notification settings
- Feedback and support forms
- Blocked users and legal pages

### Subscription System
- Monthly and yearly plan selection
- Premium feature showcase

### Custom UI System
- Reusable widgets
- Centralized theme colors and typography
- Responsive layouts
- Custom bottom navigation bar
